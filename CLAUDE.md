# CLAUDE.md - Nexora AI Guidelines & Cheatsheet

## Project Commands

### Backend (Python / FastAPI)
- Setup virtualenv: `python -m venv venv`
- Install dependencies: `pip install -r backend/requirements.txt`
- Run Backend Dev Server: `uvicorn backend.app.main:app --reload --port 8000`
- Run Tests: `pytest backend/tests -v`

### Frontend (Next.js 14 / TypeScript)
- Install dependencies: `npm install` (in `frontend/`)
- Run Frontend Dev Server: `npm run dev` (in `frontend/`, default port 3000)
- Build Production Frontend: `npm run build` (in `frontend/`)

### Docker Compose
- Launch full platform stack: `docker-compose up --build`

## Architectural Principles
1. **Zero Hallucination / Evidence Driven**: Every response generated by an agent must include backing evidence (SQL query, metric calculation, or dataset vector citation).
2. **Strict Multi-Agent Routing**: User queries are analyzed by the **Planner Agent**. Only target department agents (`Sales`, `Finance`, `HR`, `Marketing`, `Operations`) execute in parallel.
3. **No Direct Inter-Agent Chatter**: Department agents never call each other directly. All intermediate outputs are formatted in Pydantic JSON and returned to the Planner.
4. **Sentinel AI Monitoring**: Async background service continuously evaluates incoming data streams and creates tiered alerts (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
