# Frontend Design System & UI Architecture - Nexora AI

## 1. Aesthetic Direction
- **Theme**: Luxury Obsidian Black (`#08080A`), Metallic Slate Borders (`rgba(255,255,255,0.08)`), High-Contrast Pure White Text (`#FFFFFF`), Muted Text (`#8A8F98`), Accent Glow (`rgba(0, 229, 255, 0.15)` and `rgba(16, 185, 129, 0.15)`).
- **Typography**:
  - Headings: `Instrument Serif`, `Georgia`, serif (Editorial Executive look).
  - Body & UI: `Inter`, system-ui, sans-serif (Precision engineering look).

---

## 2. Dynamic Layout Components

### 2.1 Landing Page Components
- **Hero Section**: Dynamic particle background, animated headline, CTAs, live interactive dashboard mockup.
- **Bento Grid Feature Showcase**: Interactive cards detailing Enterprise Memory, Sentinel AI anomaly monitoring, 5 Department Agents, and Evidence Validation.
- **Workflow & Architecture Visualization**: Micro-animated pipeline diagram showing parallel agent execution.
- **Pricing & FAQ**: Interactive tier comparison cards and accessible accordion components.

### 2.2 Executive SaaS Dashboard Layout
- **Sidebar**: Collapsible glass sidebar with route switches (Overview, Executive Query, Data Ingestion, Sentinel AI Alerts, Settings).
- **Executive Command Bar (`Ctrl+K`)**: Global search & instant query execution palette.
- **Bento Overview**: Dynamic KPI cards with live trend sparks, department activity status, and Sentinel alerts widget.
- **AI Query Workspace**: Multi-turn executive query interface displaying Planner breakdown steps, agent JSON streams, Recharts graphs, and Evidence Inspector.
